# Portfolio

This repository contains a minimal, static portfolio site scaffold.

Getting started
- Open `index.html` in a browser or run a local static server.

Quick local server (Python 3):
```
python3 -m http.server 8000

# then open http://localhost:8000 in your browser
```

Files added
- `index.html` — main page
- `css/styles.css` — site styles
- `js/script.js` — small interactions (theme toggle, contact mailto)

Next steps
- Replace placeholder content with your name, bio, and project links.
- Add images to an `assets/` folder and update the project cards.
